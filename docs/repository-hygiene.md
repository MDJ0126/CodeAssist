# 저장소 파일 관리

## Git에 포함

제품 소스, 테스트·자동화 소스, 빌드 스크립트, 사용자 문서와 검토된 검증 근거를 포함합니다.
이미 추적 중인 검증 캡처·로그·분석 데이터는 기존 문서의 근거이므로 보존합니다.
현재 배포의 검토된 보고서는 `docs/validation/display-source-175/`에 있습니다.

## 로컬에만 보관

- `installers/<버전>/`: VSIX, 체크섬과 배포 준비 파일. 배포는 GitHub Releases를 사용합니다.
- `.local/`, bin/obj: 인덱스·개인 로그·빌드 캐시.
- `tools/` 아래 EXE·DLL, Python 바이트코드: 소스로 재생성하는 검사 실행물.
- `docs/validation/`의 새 원시 실행 결과와 과거 자동 생성 HTML 보고서.

새 검증 결과를 공개할 때는 개인정보·경로·중복 캡처를 검토하고 `.gitignore`에 해당 보고서 폴더 예외를 추가한 뒤 필요한 파일만 올립니다. `git add -f`로 원시 실행 폴더 전체를 올리지 않습니다.

## 정리 원칙

미추적 소스와 과거 실행 근거는 필요 없다고 단정해 삭제하지 않습니다. 검토되지 않은 기존 작업은 그대로 보존합니다.
공개된 커밋·릴리즈 태그는 재작성하거나 강제 푸시하지 않습니다.
