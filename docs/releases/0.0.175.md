# CodeAssist 0.0.175

Display 및 Source Links의 남은 구성과 기능 연결을 보완했습니다.

- Display: 통합 기본 메뉴 전환, 매크로 미리보기·서식·원본 동시 표시, 주석·Doxygen·구조 키워드 정보.
- Source Links: URL·파일 보기·외부 도구 공급자, GitHub·FogBugz·Jira 예제, 인수 처리, XML 공급자 정의 가져오기, 두 번 클릭·Alt+클릭 동작.
- 옵션 18종의 구성 보완과 참조 창의 다크·라이트 테마 및 빈 결과 안내를 포함합니다.
- VS2019 패키지와 VS2022 이상용 Modern 패키지를 제공합니다.

보고서: docs/validation/display-source-175/index.html

구성 점수와 자동 회귀 검사 결과는 전체 VA 기능의 실행 동등성 인증을 의미하지 않습니다. 이번 버전은 Computer Use나 새 IDE 입력 대조 없이 검증합니다.
