# 첫 실행 · Welcome

Welcome은 코드 파일과 같은 문서 영역에 열립니다. Tools → CodeAssist: Welcome 또는 도구 모음 맨 뒤 Welcome 버튼으로 다시 엽니다. 두 번째 버튼은 파일 열기입니다.

첫 실행 안내는 전체 통합(완성·색상 켜기)과 기본 통합을 선택합니다. 설정을 적용해야 완료 상태가 저장됩니다. 나중에 또는 창 닫기는 완료로 처리하지 않습니다.

시작 순서는 Welcome → 상단 안내 → 통합 설정 팝업입니다. Welcome 시작 표시와 안내 숨김은 설정에서 조정합니다. 사용자 LocalAppData의 CodeAssist/startup.xml에 저장하고 이전 파일을 startup.xml.bak로 보존합니다.

옵션 창은 Tools → CodeAssist: Settings에서 엽니다. 편집 초안은 저장할 때 적용하며 취소하면 유지하지 않습니다. 색상 설정에는 클래스·변수·함수·매크로 팔레트와 VS 기본 추천 색상 옵션이 있습니다.

상단 안내의 Enable은 기본 프로젝트 구문 검사를 실행합니다. VA의 전체 코드 검사 엔진과 같은 기능이라고 검증하지 않았습니다.
