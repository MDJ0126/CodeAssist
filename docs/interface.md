# CodeAssist 인터페이스

[원본 유사도·구현 기능 수](progress-audit.html)에서 현재 검증 범위를 확인하실 수 있습니다. 과거 빌드의 기록은 [인계 문서](handoff.html)에 보존합니다.

## 도구 모음

VA에서 관찰한 명령 순서에 맞춰 설정, 파일 열기, 심볼 찾기, 참조 찾기, 문맥상 이전, 문맥상 다음, 스니펫, 맞춤법 검사, 대응 파일, 전체 중단점 건너뛰기, 현재 스레드에 중단점 연결을 배치했습니다. 맨 뒤에 CodeAssist Welcome이 있습니다. 두 번째 버튼은 파일 열기입니다. VS 도구 모음의 추가 항목 메뉴에서 버튼을 표시하거나 숨길 수 있습니다.

맞춤법은 VS 기본 명령을 사용합니다. 중단점 버튼은 적용 가능한 디버그 문맥에서만 활성화됩니다. 해당 버튼의 실제 디버그 세션 검증은 남아 있습니다.

## Welcome과 옵션

Tools → CodeAssist: Welcome 또는 도구 모음 맨 뒤 Welcome으로 코드 파일 옆 문서 탭을 엽니다. Tools → CodeAssist: Settings 또는 첫 번째 설정 버튼으로 옵션을 엽니다. 첫 실행 안내는 전체/기본 통합을 선택합니다. Welcome은 문서이며 옵션 창은 별도 대화상자입니다.

옵션은 검색·왼쪽 분류 트리·오른쪽 설정·저장/취소로 구성했습니다. 저장할 때 적용하고 취소하면 초안을 버립니다. [한영 번역표](localization.html)는 다른 언어를 추가할 수 있는 XML 테이블입니다.

## 연결된 편집 옵션

|범주|동작|
|---|---|
|Editor|괄호·따옴표, 함수 괄호 간격, 닫는 중괄호 위치, 주석 이어쓰기, 선택 영역 감싸기, 붙여넣기 뒤 서식|
|Smart Select|작은 단위 확장, 현재 단어 시작, 대소문자 경계, 밑줄 경계, 공백 제외|
|Coloring|심볼 팔레트, VS 기본 추천 색상 사용, 추천 팔레트 복원|
|Display|심볼 Quick Info, 편집기 상단 Context Bar|
|검사|끄기·파일별·프로젝트 기본 구문 검사|

추천 목록의 자체 아이콘과 색상을 제공합니다. VS 기본 추천 색상을 선택하면 자체 전경색 덮어쓰기를 해제합니다. 원본 아이콘/필터/전체 의미 분석과의 동등성은 미완료입니다.

Editor와 Smart Select는 REA로 읽은 원본 대화상자 리소스 순서를 참고했습니다. 아직 없는 토글은 작동하는 것처럼 표시하지 않습니다. 원본의 모든 옵션과 공장 기본값을 복원한 상태는 아닙니다.

## 상단 안내

Enable은 프로젝트 C/C++ 기본 구문 검사를 실행하고 오류 목록에 후보를 표시합니다. Disable은 진단을 끄고 검사를 취소합니다. Use per-file engine은 열린 파일 검사를 사용합니다. 전체 컴파일러/clang-tidy 분석과 동일하지 않습니다. 선택은 사용자 단위로 저장하며 솔루션별 기본값 체크박스는 미구현입니다.
