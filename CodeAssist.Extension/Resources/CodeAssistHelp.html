기능색상탐색검사단축키

시작하기

상단 바나나 아이콘으로 Options를 엽니다. 왼쪽 검색과 분류 트리에서 설정을 선택하고 저장하세요. Welcome은 코드 파일과 같은 문서 영역에서 엽니다.

주요 기능

범용 C/C++ 탐색·완성·색상 표시와 Unreal 매크로 지원, 클립보드 기록, 스니펫·선택 확장을 제공합니다. 기능별 VA 전체 동등성은 미검증입니다.

색상

Editor → Coloring에서 향상된 색상과 클래스·변수·함수·매크로 색상을 선택합니다. #RRGGBB 값을 입력하고 저장하면 열린 편집기에도 다시 적용합니다.

탐색

편집기 Context Bar에는 현재 파일 경로, 함수 후보와 Go·대응 파일 버튼이 있습니다. 함수 목록은 열 때 현재 문서를 분석합니다. 선언·호출을 구분하는 컴파일러 메서드 목록과 동일하지 않습니다.

코드 검사

상단 Enable은 프로젝트 전체 기본 구문 검사를 시작하고 오류 목록에 결과를 표시합니다. Disable은 CodeAssist 진단을 끄고, Use per-file engine은 열린 문서별 진단을 사용합니다. 설정은 사용자 단위로 저장됩니다. 전체 프로젝트 검사는 C/C++ 로컬 프로젝트 파일의 괄호·제어문 구문 후보 검사이며 VA/clang-tidy 전체 검사 집합과 같지 않습니다.
